# 漢字で韓国語（LearningCorean）

韓国語の漢字語（한자어）の**発音を聞き**、**漢字の字幕**をヒントに**日本語で答える**学習アプリです。
ビルド不要の静的 Web アプリで、`index.html` をブラウザで開くだけで動きます。

## 遊び方

1. レベル・字幕・回答方法・読み上げ速度を選んで「スタート」
2. 韓国語の音声が流れる（🔊 もう一度 / 🐢 ゆっくり）
3. 字幕の漢字（例：`學校`）をヒントに日本語で答える（`学校` / `がっこう` / `ガッコウ` どれでも正解）
4. 答え合わせで漢字の上にハングルの音（학·교）が表示され、漢字と音の対応が覚えられます

### 設定

| 項目 | 内容 |
| --- | --- |
| レベル | 初級 / 中級 / すべて（全 109 語） |
| 字幕 | 漢字のみ / 漢字＋ハングル / なし（音声のみ、ヒントで漢字表示） |
| 回答方法 | 入力 / 4択（キー 1〜4 で選択） |
| 苦手な単語だけ | 間違えた単語（2回連続正解で卒業）から出題 |

ショートカット：`Space` で再生、`Enter` で次へ。学習記録はブラウザの localStorage に保存されます。

`공부（工夫）＝勉強`、`생일（生日）＝誕生日` のように日本語と意味がずれる語には 💡 補足が出ます。

## 音声について

ブラウザの Web Speech API（`speechSynthesis`, `ko-KR`）で読み上げます。
韓国語の音声が端末に無い場合は警告が出るので、OS の設定で韓国語の読み上げ音声を追加してください。

## 構成

```
index.html      画面
css/style.css   スタイル（ダークモード対応）
js/words.js     単語データ（ko / hanja / ja / level / note）
js/judge.js     解答の正規化・判定
js/app.js       クイズ本体
test/run.js     データ整合性と判定のテスト（node test/run.js）
```

単語を追加するときは `js/words.js` に 1 行足してください。漢字とハングルは 1 字 1 音節で対応させる必要があります（テストで検査）。
